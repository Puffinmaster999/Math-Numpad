# Math Numpad
this is a [**Hack Club**](https://hackclub.com) project!

this is a numpad that i made in [ergogen](https://ergogen.xyz/)!

---
i first saw this amazing [youtube video](https://youtu.be/7UXsD7nSfDY) where this youtuber named Christian Selig made a custom keyboard that suited his liking perfectly! however, the keyboard that i am using is so good for my personal liking that i didn't want to change my entire keyboard. rather as a student still doing math i thought that it would be nice to have a numpad that would be custom made for me! the keyboard layout was inspired by the Casio FX-300ES PLUS 2nd Edition calculator. it has a lot of the necessary math functions and i was able to use that as my base to add my functions on top of. if you look at the overall layout of the keyboard it will be similar to the math functions that exist on this calculator! however the most important thing for me was the ability for the numpad to be able to do some math! this way if i want to use this as a calculator i can! the only issue that i see is that this might not be allowed for online tests. however for personal use i think this is a perfect tool for students alike!
